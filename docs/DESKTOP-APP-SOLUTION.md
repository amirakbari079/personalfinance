# مستند معماری و راهکار تبدیل PersonalFinance به اپلیکیشن دسکتاپ ویندوز (Desktop Installable Application)

این سند تحلیل فنی، مقایسه سناریوها، و پیاده‌سازی گام‌به‌گام تبدیل پروژه **PersonalFinance** به یک نرم‌افزار دسکتاپ مستقل، تک‌کلیکی (Single-Click) و قابل نصب برای سیستم‌عامل ویندوز را شرح می‌دهد.

---

## ۱. زمینه معماری پروژه و چالش‌ها

پروژه PersonalFinance از ۳ مؤلفه اصلی تشکیل شده است:
1. **دیتابیس (Database)**: PostgreSQL روی پورت ۵۴۳۲ (که به صورت سرویس ویندوز یا محلی مدیریت می‌شود).
2. **بک‌اند (Backend)**: Java 21 + Spring Boot 3.5.x روی پورت ۸۰۸۰.
3. **فرانت‌اند (Frontend)**: Next.js 15 (App Router با React 19) روی پورت ۳۰۰۰.

### چالش اصلی در تبدیل به اپلیکیشن دسکتاپ:
برخلاف اپلیکیشن‌های تک‌لایه (مثل یک وب‌سایت استاتیک ساده)، در این پروژه فرانت‌اند SSR (Next.js) و بک‌اند سازمانی (Spring Boot) همراه با دیتابیس رابطه‌ای باید همزمان مدیریت شوند. هدف نهایی این است که **کاربر نهایی هیچ‌گونه پنجره مشکی خط فرمان (CMD / PowerShell) نبیند، با یک دابل‌کلیک روی آیکون برنامه آن را اجرا کند، و محیط نرم‌افزار به صورت یک پنجره تمیز دسکتاپ بدون نوار آدرس مرورگر (App Window) بالا بیاید**.

## ۲. بررسی جامع ۳ سناریوی مطرح‌شده

| شاخص مقایسه | سناریو الف: Edge App Mode + Silent Runner | سناریو ب: بسته‌بندی نصاب تک‌فایلی (Inno Setup) | سناریو ج: فریم‌ورک‌های نیتیو (Electron / Tauri) |
| :--- | :--- | :--- | :--- |
| **حجم پکیج اضافی (Footprint)** | **۰ مگابایت** (از رانتایم موجود ویندوز استفاده می‌کند) | **بسیار کم** (~۵ تا ۱۰ مگابایت فشرده) | **بسیار بالا** (Electron: ۱۵۰+ مگابایت) |
| **مصرف رم (Memory Overhead)** | **کمترین حالت** (~۵۰ تا ۸۰ مگابایت اضافه) | بر اساس سناریوی اجرایی | **بسیار سنگین** (افزودن ۲۰۰-۳۰۰ مگابایت رم مجزا فقط برای کرومیوم الکتورن) |
| **سازگاری با Next.js 15 App Router** | **۱۰۰٪ سازگار و بدون ریسک** (محیط استاندارد وب) | **۱۰۰٪ سازگار** | **شکننده** (الکترون نیاز به هک ASAR/Node child process دارد؛ توری با SSR سرور اکشن سازگار نیست) |
| **پیچیدگی بیلد و نگهداری** | **بسیار آسان** (اسکریپت ساده، بدون وابستگی ثالث) | **استاندارد و اثبات‌شده** در ویندوز | **بسیار بالا** (نیاز به کامپایلر Rust، ابزارهای C++، electron-builder و ساینینگ) |
| **تجربه کاربری دسکتاپ** | پنجره فریم‌لس بدون URL bar، آیکون و تسک‌بار مجزا | نصب ویزاردی، ایجاد شورتکات و آن‌اینستالر | اپ دسکتاپ نیتیو |

### تحلیل تفصیلی سناریوها:

### سناریو الف) میانبر هوشمند با حالت مستقل مرورگر (PWA / Edge App Mode) + اسکریپت بی‌صدا
- **مکانیسم عملکرد**:
  ویندوز ۱۰ و ۱۱ به صورت پیش‌فرض مجهز به Microsoft Edge (مبتنی بر کرومیوم) هستند. سوییچ `--app="http://127.0.0.1:3000"` هر آدرس وبی را در یک پنجره مستقل سیستمی (بدون تب، بدون تولبار و آدرس‌بار، با ابعاد مشخص و کنترل‌های دسکتاپ) باز می‌کند.
  همچنین با افزودن سوییچ `--user-data-dir="%LocalAppData%\PersonalFinance\AppProfile"`، یک پروفایل ایزوله ساخته می‌شود تا افزونه‌ها یا کوکی‌های مرورگر شخصی کاربر هیچ تداخلی با اپلیکیشن مالی ایجاد نکنند.
- **اجرای بی‌صدا (Zero Console Flash)**:
  برای حذف پنجره سیاه CMD، یک لانچر بومی فوق‌سبک (`PersonalFinance.exe` با حجم ۱۸ کیلوبایت کامپایل‌شده با کامپایلر استاندارد دات‌نت ویندوز `csc.exe`) یا اسکریپت VBScript آماده شد که در پس‌زمینه اسکریپت PowerShell را به شکل کاملاً پنهان اجرا می‌کند.

### سناریو ب) بسته‌بندی نصاب تک‌فایلی نصبی ویندوز (Inno Setup)
- **مکانیسم عملکرد**:
  این سناریو یک فایل راه‌انداز استاندارد `PersonalFinance-Setup.exe` ایجاد می‌کند.
  - کاربر مسیر نصب را انتخاب می‌کند (به صورت پیش‌فرض در `%LocalAppData%\PersonalFinance` تا نیاز به دسترسی Administrator نباشد).
  - فایل‌ها، آیکون‌ها، اسکریپت‌ها و ساختار پروژه کپی می‌شوند.
  - میانبر دسکتاپ و پوشه منوی استارت با آیکون بومی ساخته می‌شود.
  - ثبت در لیست نرم‌افزارهای کنترل پنل (Add/Remove Programs) برای حذف آسان (Uninstall).
- **ارزیابی**: به عنوان لایه توزیع (Distribution)، این روش ایده‌آل‌ترین فرمت برای تحویل به مشتری یا کاربران است.

### سناریو ج) فریم‌ورک‌های نیتیو (Electron یا Tauri)
- **بررسی Electron**:
  - رانتایم Electron شامل یک نسخه کامل از Chromium و Node.js است.
  - حجم پروژه را ۱۲۰ تا ۲۰۰ مگابایت افزایش می‌دهد.
  - در حال حاضر پروژه برای اجرای Spring Boot به حدود ۳۰۰ تا ۵۰۰ مگابایت رم و برای نود به حدود ۱۰۰ مگابایت نیاز دارد. افزودن پروسه‌های سنگین Electron رم مصرفی را به مرز ۱ گیگابایت می‌رساند که برای یک برنامه مالی روی سیستم‌های کاربران عادی نامناسب است.
  - بسته‌بندی Next.js 15 App Router با ساختار ASAR در الکترون چالش‌های سازگاری زیادی دارد.
- **بررسی Tauri**:
  - توری با Rust نوشته شده و از WebView2 استفاده می‌کند؛ حجم فایل کم است.
  - **اما اشکال کلیدی توری**: توری برای فرانت‌های Static SPA طراحی شده است. Next.js 15 در این پروژه شامل سرور، ری‌رایت‌های API و رندرهای داینامیک است. توری برای اجرای چنین پروژه‌ای باید دو پردازه سنگین جانبی (Sidecar) یعنی Node.js و Spring Boot JAR را مدیریت کند. هماهنگی مرگ پردازه‌ها، پورت‌ها و خطایابی دو Sidecar داخل هسته Rust توری پیچیدگی عظیمی بدون ارزش افزوده واقعی تحمیل می‌کند.

## ۳. پیشنهاد بهترین و سبک‌ترین روش (The Recommended Solution)

**پیشنهاد نهایی: راهکار ترکیبی هوشمند (Edge App Mode + Native C# Launcher + Inno Setup Package)**

این ترکیب مزایای همه روش‌ها را همزمان دارد:
1. **ظاهر ۱۰۰٪ دسکتاپ**: باز شدن اپلیکیشن در پنجره اختصاصی بدون آدرس‌بار، با تایتل فارسی «حسابداری شخصی»، آیکون اختصاصی و تسک‌بار مجزا.
2. **سبک‌ترین وزن ممکن**: بدون افزودن مگابایت‌های اضافی فریم‌ورک‌های سنگین.
3. **پایداری کامل**: استفاده مستقیم از توان Next.js 15 و Spring Boot بدون لایه‌های شکننده شبیه‌ساز.
4. **شورتکات و نصاب ویندوز**: شورتکات تک‌کلیکی روی دسکتاپ و منوی استارت همراه با امکان ساخت نصاب رسمی با Inno Setup.

## ۵. نحوه استفاده گام‌به‌گام

### الف) ساخت میانبر روی دسکتاپ و استارت منو (روش سریع):
تنها کافی است دستور زیر را در ریشه پروژه اجرا کنید:
```powershell
.\scripts\install-desktop-shortcuts.ps1
```
پس از اجرا:
- یک میانبر زیبا با آیکون حسابداری به نام **PersonalFinance** روی دسکتاپ شما ظاهر می‌شود.
- در منوی استارت ویندوز پوشه `PersonalFinance` با گزینه‌های اجرا و توقف اضافه می‌شود.
- با دابل‌کلیک روی آیکون دسکتاپ، برنامه در حالت پنجره اختصاصی دسکتاپی باز می‌شود.

### ب) ساخت پکیج نصابی ویندوز (Setup.exe):
1. نرم‌افزار رایگان [Inno Setup](https://jrsoftware.org/isdl.php) را نصب کنید.
2. دستور زیر را اجرا کنید:
   ```powershell
   .\scripts\build-installer.ps1
   ```
   یا فایل `installer/setup.iss` را در Inno Setup باز کرده و دکمه **Compile** را بزنید.
3. فایل نصاب در پوشه `installer/dist/PersonalFinance-Setup-v1.0.0.exe` ساخته خواهد شد.
