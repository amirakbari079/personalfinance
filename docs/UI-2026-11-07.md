# UI update — 2026-11-07

The accepted UI baseline is Git tag `ui-baseline-2026-11-07` at commit `83bcf8a` on branch `codex/cool-wide-layout`. Use that tag for visual comparisons; do not assume this foundation branch is the visual source of truth.

The default brown secondary accent was replaced with blue/cyan in light and evergreen dark themes. The exact previous built-in stored color set migrates to the new defaults; genuine custom colors and the midnight/amethyst themes remain supported.

Desktop page width limits were removed from the dashboard, management pages and intelligence area. Side navigation and responsive padding remain; forms retain readable widths.

Validation at acceptance: Next.js production build, TypeScript, 9 frontend tests, and browser checks at 375, 768, 1440 and 1920 pixels with no horizontal overflow. At 1920 pixels, settings content used 1642 of 1674 workspace pixels.

Foundation development must preserve this UI direction. Transfer visual changes selectively and validate them against the tagged baseline before release.
