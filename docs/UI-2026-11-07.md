# UI update — 2026-11-07

Removed the default brown secondary accent in favor of blue/cyan in light and evergreen dark themes. The exact previous built-in stored color set migrates to the new defaults; custom colors and the midnight/amethyst themes stay supported.

Removed desktop page width limits, including dashboard, management pages and intelligence. Side navigation and responsive padding remain; forms retain readable widths.

Validation: Next.js production build, TypeScript, 9 frontend tests; isolated browser checks at 375, 768, 1440 and 1920 pixels, with no horizontal overflow. At 1920 pixels, settings content uses 1642 of 1674 workspace pixels (remaining space is padding).

This release changes frontend appearance only. Backend and production database migrations were not changed. The unfinished finance foundation remains in its separate worktree/branch. The prior frontend build is saved locally under `.run/frontend-before-cool-20261107`.
